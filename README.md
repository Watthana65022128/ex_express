# Express CRUD API

Install Node.js 18+ and npm, then run `npm install` and `npm run dev` (or `npm start`).

Endpoints under `/api/items`: GET list, GET `/:id`, POST `{ "name": "...", "description": "..." }`, PUT `/:id`, DELETE `/:id`. Data is held in memory and resets when the server restarts. Health: `/api/health`.
